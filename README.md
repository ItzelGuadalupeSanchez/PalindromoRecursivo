# Palíndromo Recursivo en Java

## Descripción
Este proyecto consiste en un programa desarrollado en Java que permite verificar si una palabra o frase es un palíndromo utilizando recursividad.

Un palíndromo es una palabra que se lee igual de izquierda a derecha que de derecha a izquierda.

## Funcionamiento
El programa utiliza el patrón Wrapper y dos métodos:

- **verificar():** valida la palabra, elimina espacios y convierte las letras a minúsculas.
- **verificarRecursivo():** compara la primera y última letra y continúa hasta llegar al centro.

## Casos de prueba
- reconocer: true
- radar: true
- hola: false
- Anita lava la tina: true
- Cadena vacía: true
- Una sola letra: true
- Valor nulo: false
